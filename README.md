# PCB Network Optimization

This project models PCB components as a weighted graph and finds the Minimum Spanning Tree (MST) with minimum total connection cost using Graph, BFS, DFS, and Kruskal with Union-Find.

## Project Scope

- Graph representation
- Adjacency List and Adjacency Matrix
- BFS and DFS
- Kruskal MST algorithm with Union-Find
- Graph visualization
- Dynamic node updates

## Team Responsibilities

- **feature/graph-core**  
  Graph, Node, Edge classes, adjacency list, adjacency matrix, add_node, add_edge

- **feature/bfs-dfs**  
  Queue, Stack, BFS, DFS, connected graph check

- **feature/kruskal-unionfind**  
  Union-Find, Kruskal MST, cycle prevention, total cost calculation

- **feature/ui-visualization**  
  Graph visualization, MST highlighting, interface controls

- **feature/docs-integration**  
  README updates, JSON test data, integration notes, report skeleton
