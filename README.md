# pcb-network-optimization
PCB Connection Network Optimization project using Graph, BFS, DFS, and MST algorithms
This project models PCB components as a weighted graph and finds the Minimum Spanning Tree (MST) with minimum total connection cost.

## Project Scope
- Graph representation
- Adjacency List and Adjacency Matrix
- BFS and DFS
- Kruskal MST algorithm with Union-Find
- Graph visualization
- Dynamic node updates
